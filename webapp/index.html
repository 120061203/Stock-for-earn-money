資料與計算方式

漲幅

以證交所 MIS 的有效最後成交價及昨收／參考價計算，缺失時用富果實際成交資料補查。無有效成交價、資料日期非今天的股票不列入當次掃描。

量能倍數

今日整股累計量 ÷ 前 N 個交易日平均成交股數。MIS 累計張數換算成股，歷史日線成交量優先使用 FinMind，缺失時改查富果。富果整股累計張數亦換算成股；個股詳情列出實際來源。日均量不含今天；盤中不推估全日量。

盤中自動更新

開啟後立即查詢一次，之後在每次掃描完成後，依設定間隔重新查詢最新漲幅與成交量。全市場查詢需時間，各檔成交時間可能不同，資料時效依來源回傳為準。頁面切至背景時暫停新增查詢，回到前景後恢復。停止、取消勾選或發生錯誤時關閉自動更新。量比始終使用當日累計量，不推估收盤量。

更新與資料範圍

畫面先顯示最近一次完成的掃描。調整條件會篩選已下載資料；漲幅超出已下載範圍或變更日均量天數時，需要更新行情。遇 API 額度限制會揭露未完成檢查數，不會當成不符合。

股票名單為本機既有上市櫃普通股清單，不含 ETF、特別股、權證及興櫃；名單日期可在資料卡查看。量價篩選不等於買進訊號。
